# BudgetBuddyBot 🧭💸

Телеграм-бот для личных финансов
- добавляй траты за секунды
- веди категории
- смотри статистику и держи бюджет под контролем

**Незаменим** в повседневной рутине — быстро и удобно 🚀

---

## ✨ Что умеет бот

- 🧾 **Добавлять траты**: сумма, категория, заметка — одним сообщением
- 🗂️ **Категории**: создавать, удалять
- 📊 **Статистика**: за день/неделю/месяц, по категориям, средние значения
- 🕒 **Последние траты**: быстрый список последних операций
- 🔎 **Фильтры**: по дате/категории для истории и отчетов
- 🛡️ **Надежность**: очередь сообщений и ретраи, чтобы ничего не потерялось

---

## 🧠 Команды

- `/start → запустит бота
- `/manu` → покажет менюшку
- `/about` → покажет информацию о боте

---

## 🧩 Архитектура

- **TgApiService** 🤖 — прием команд из Telegram, валидация, отправка событий
- **SpendingTrackerService** 💾 — доменная логика: траты, категории
- **StatisticsService** 📈 — агрегации и отчеты
- **Shared/SharedTypes** 🧱 — общие контракты, DTO, утилиты

---

## 📒 Инфраструктура

- **MassTransit + RabbitMQ** 📬 — обмен событиями между сервисами
- **EF Core + PostgreSQL** 🐘 — хранилище
- **Serilog** 🪵 — структурные логи
- **Central Package Management** — единые версии NuGet в `Directory.Packages.props`
- **.editorconfig + анализаторы** — качество кода на сборке

---

## 🛣️ Роадмап

- ⏱️ Повторяющиеся платежи и напоминания
- 📤 Экспорт/импорт (CSV/Excel)
